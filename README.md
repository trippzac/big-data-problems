# big-data-problems
This is problems solved in a big data course primarily coded in R.

## What is this repository?
This comes from a course taken at University of Michigan (BIOSTAT 625) on Computing with Big Data. The problems solved here are examples of my ability to create tidy code that runs efficiently on large sets of data. As the course progresses, I plan to add more code from a variety of tools such as PyTorch, Hadoop, Spark, and AWS.
